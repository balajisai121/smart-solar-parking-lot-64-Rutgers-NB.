# Smart Solar Parking Lot Project

This repository contains the design, planning, and implementation details of the Smart Solar Parking Lot project. The project integrates solar energy, EV charging, and IoT-based smart parking management to promote sustainable urban infrastructure.

## Key Highlights
- **Power Generation**: 1,960 solar panels generating 1,723.7 MW.
- **Total Cost**: $1,878,500 (estimated).
- **Key Features**:
  - Solar canopy over Parking Lot 64.
  - IoT-enabled real-time parking management.
  - EV charging stations with smart monitoring.
## Smart Parking App

The Smart Parking App is an integral part of the Smart Solar Parking Lot project. It provides real-time parking data, EV charging station availability, and energy monitoring via a user-friendly interface.

### Features
- Real-time parking space availability
- EV charging station tracking
- Energy generation and usage display
- Automated vehicle recognition
- Secure payments for parking and charging

### Agile Development Plan
The app was developed using Agile methodologies, with iterative sprints focusing on core functionalities and user feedback.

#### Sprints Overview
1. **Sprint 1**: App design and prototyping  
   - Developed wireframes and UI/UX designs.  
   - Conducted usability testing.

2. **Sprint 2**: Basic functionality implementation  
   - User registration, parking availability, and payment processing.  
   - Real-time data integration.

3. **Sprint 3**: Integration and testing  
   - Backend synchronization and rigorous testing.  
   - Cross-platform compatibility ensured.

4. **Sprint 4**: Advanced features  
   - Added vehicle recognition, energy tracking, and reporting.  
   - Improved user navigation with geolocation services.

5. **Sprint 5**: Optimization and refinement  
   - Performance optimization and final testing.

### User Stories
- **Commuter**: As a commuter, I want to find available EV charging stations easily.  
- **Visitor**: As a visitor, I want my vehicle to be recognized automatically for seamless entry and exit.  
- **Driver**: As a driver, I want real-time parking availability to save time.  
- **Manager**: As a lot manager, I want data analytics on parking usage for better operations.

### Tech Stack
- **Frontend**: React Native (for cross-platform mobile app development)
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **IoT Integration**: MQTT protocol for real-time updates
